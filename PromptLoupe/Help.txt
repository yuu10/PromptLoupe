# PromptLoupe 使い方
>> AI生成画像に埋め込まれたメタデータ(プロンプトやパラメーター)を見ながら、並び替え・絞り込みして閲覧する画像ビューアです。このウィンドウは Esc キーで閉じられます。
! PromptLoupe は Windows・Mac・Linux で使えます。OS によって違うところは、そのつど書いています。キーの「Ctrl」は、Mac では「⌘」です。

## 1. 画像を開く
- メニュー「ファイル → フォルダを開く」で、フォルダ内の画像を一覧にします。
- 「ファイル → 画像を開く」では、選んだ画像のあるフォルダを開き、その画像を選択した状態にします。
- フォルダや画像を、ウィンドウにドラッグ＆ドロップしても開けます(ドロップしたファイルやフォルダを開きます)。
- 表示できる画像形式は PNG / JPEG / WebP / BMP / GIF / TIFF / HEIC です。GIF は先頭のフレーム、TIFF は先頭のページだけを表示します。WebP は、OS に拡張機能を入れなくても表示できます。**HEIC は OS の機能で読みます**。Windows では「HEIF 画像拡張機能」と「HEVC ビデオ拡張機能」(Microsoft Store)が、Linux では libheif と HEVC のプラグイン(Ubuntu なら `libheif-plugin-libde265`)が必要です。Mac はそのまま表示できます。
- スマホやカメラで撮った JPEG・WebP は、EXIF の回転情報に従って、正しい向きで表示します(サムネイルも同じ)。
サブフォルダの画像も読み込みたいときは、左のフォルダツリーの上にある「サブフォルダ」か、メニュー「設定 → サブフォルダの読み込み」で深さを選びます(含めない / 1階層まで / 2階層まで / 3階層まで / 無制限。どちらも同じ設定です)。画像が非常に多いときは、深さを制限すると読み込みが速くなります。開いたフォルダの直下にあるサブフォルダが1階層目です。
**フォルダのパス。** 絞り込み欄の上に、開いているフォルダのパスが出ます。
- フォルダ名をクリックすると、そのフォルダへ移動します。
- 空いたところをクリックすると(Ctrl+L / Alt+D でも)、パスを手で入力できます。Enter で移動、Esc で取り消しです。前後の「"」は外し、`%USERPROFILE%` などの環境変数と、先頭の `~`(ホーム)も使えます。画像のパスを入れると、そのフォルダを開いて、その画像を選びます。見つからないときは、欄の枠が赤くなります。
- 左の「←」「→」「↑」で、前のフォルダに戻る・進む・親フォルダへ移動します(Alt+← / Alt+→ / Alt+↑、マウスの戻る・進むボタンでも。Mac は ⌘[ / ⌘] / ⌘↑)。右の「参照...」は「ファイル → フォルダを開く」と同じです。
- パスの欄は、メニュー「設定 → フォルダのパスを表示」で隠せます。隠していても、戻る・進む・親フォルダへのキーは使えます。
**フォルダツリー。** 左側の上半分に、フォルダの一覧が木の形で出ます。フォルダをクリックすると、そのフォルダを開きます。
- いちばん上には、よく使う場所(ピクチャ・デスクトップ・ドキュメント・ダウンロード。Mac・Linux はホームも)と、ドライブ(Mac・Linux は「ルート (/)」など)が並びます。
- フォルダを開くと、ツリーもそのフォルダまで開いて、選んだ状態になります(パスの欄や「ファイル → フォルダを開く」で開いたときも)。
- 隠しフォルダ・システムフォルダ(Mac・Linux は「.」で始まる名前)は出しません。フォルダの中の画像の枚数は数えません。
- 右クリックで、ファイルマネージャーで表示・フォルダのパスをコピー・最新の情報に更新(ほかのアプリで作ったフォルダを出す)ができます。右クリックでは、そのフォルダを開きません。
- 見出しの「▾ フォルダ」をクリックすると最小化できます。ツリーと一覧の境目をドラッグすると、ツリーの高さを変えられます(どちらも保存されます)。
- ツリーを選んでいるあいだは、矢印キーはツリーの操作(↑↓ で移動、←→ で閉じる・開く)になり、画像の切り替えやファイル操作のキーは働きません。

## 2. 画像を見る
- **→ / PageDown / Space** — 次の画像
- **← / PageUp / Backspace** — 前の画像
- **Home / End** — 最初の画像 / 最後の画像
- **F** — フィット表示(画面に収める)
- **1** — 等倍(100%)表示
- **マウスホイール** — ポインターの位置を中心に拡大・縮小
- **ドラッグ** — 画像を移動
- **画像をダブルクリック** — 手動のズームや移動をやめて、選んでいる表示方式に戻す
- **F11** — 全画面表示の切り替え(Esc でも戻れます)
- **Ctrl+C / Ctrl+X / Ctrl+V** — 選んだファイルのコピー / 切り取り / 貼り付け
- **F2** — 名前の変更
- **Delete** — ごみ箱へ移動(設定で許可しているときだけ。Mac では ⌘+Backspace)
- **Ctrl+Shift+C** — ファイルのパスをコピー
- **Alt+Enter** — プロパティ(Windows のみ)
- **Alt+← / Alt+→ / Alt+↑** — 前のフォルダに戻る / 進む / 親フォルダへ(Mac は ⌘[ / ⌘] / ⌘↑)
- **Ctrl+L / Alt+D** — フォルダのパスを入力(Mac は ⌘L)
- **Ctrl+T** — タグの集計を開く
- **F1** — このマニュアルを開く
キー操作は、絞り込み欄や文字を入力できる欄に入力しているときは働きません(入力を優先します)。一覧の項目をクリックしてから使ってください。
画像の右下に、いまの表示倍率(実際のピクセルに対する割合)と、「フィット」「100%」「全画面」のボタンが重なって出ます。
**表示方式は引き継がれます。** 「フィット」か「100%」を選ぶと、画像を切り替えても同じ方式で開きます。選んでいる方のボタンは太字になり、次回起動時も保持されます。ホイールやドラッグで手動で変えた分は、次の画像には引き継がれません。

## 3. 並び替え
左の一覧の上にある「並び替え」で、基準を選びます。隣のボタンで、`▲ 昇順` と `▼ 降順` を切り替えます(ボタンに今の向きが表示されます)。
- 基準: ファイル名(数字を考慮した自然順) / 更新日時 / 撮影日時 / サイズ / モデル / サンプラー / ステップ数 / CFG
- 撮影日時は、写真の EXIF に記録された日時です。EXIF に撮影日時がない画像(AI 生成画像など)は、更新日時で代わりに並べます。
- モデル・サンプラー・ステップ数・CFG で並べるときは、その情報がない画像は、昇順でも降順でも常に最後になります。
- 基準が同じ画像は、ファイル名順になります。

## 4. 絞り込み
画面の上のほうにある絞り込み欄(ウィンドウの右端まで伸びている欄)に語句を入力すると、その語句を含む画像だけが一覧に残ります。入力するたびに、すぐ結果が変わります。入力欄の右端の「×」で、まとめて消せます。ステータスバーの右側に「120 件中 35 件を表示」のように件数が出ます。
- **カンマ区切りで AND 検索**
  `blue hair, 1girl` のようにカンマ( , )で区切ると、すべての語を含む画像だけを表示します。全角の「、」「，」も区切りとして使えます。カンマの前後のスペースは無視されます。語の中のスペース(`blue hair`)は、1つの語として探します。
- **スペースとアンダーバーは同じ扱い**
  `hatsune miku` と `hatsune_miku` は、どちらを入力しても、どちらの書き方のプロンプトにも一致します。A1111 系が保存する、かっこの前のバックスラッシュ(`rem_\(re:zero\)` の `\`)は無視されるので、`rem (re:zero)` でも探せます。大文字と小文字も区別しません。
- **検索対象を選ぶ**
  絞り込み欄の左の「検索対象 ▾」から、探す場所にチェックを入れます。ファイル名 / プロンプト / ネガティブプロンプト / キャラクター別プロンプト / キャラクター別ネガティブ / モデル名の6つで、最後の1つは外せません。たとえば「キャラクター別プロンプト」だけにすると、キャラクターごとのプロンプトだけから探せます。設定は保存されます。
! メタデータは、フォルダを開いたあとにバックグラウンドで読み込みます。読み込みの途中は、プロンプトでの絞り込み結果が少なく出ることがあります。ステータスバーに「メタデータ読み込み中…」が出ている間は、終わるまで待つと、結果と件数が自動で更新されます。

## 5. メタデータの見方
画面の右側のパネルに、選んでいる画像の情報が出ます。
- **ファイル / 生成元** — 画像の名前、更新日時、サイズと、どのツールで生成されたか
- **プロンプト / ネガティブプロンプト** — タグごとの小さな枠(チップ)で表示します。チップをクリックすると、そのタグが絞り込み欄に追加され(重みやかっこは外した形で入ります)、もう一度クリックすると外れます。タグ辞書を読み込むと、タグの種類ごとに色が付きます(「9. タグの色分け」を参照)。「全文を表示」で元の文章を見られ、「コピー」ボタンでクリップボードにコピーできます。
- **キャラクター別プロンプト** — NovelAI V4 / V4.5 の、キャラクターごとのプロンプトとネガティブです(該当する画像のみ表示)。人数に制限はありません。
- **パラメーター** — モデル、サンプラー、スケジューラー、ステップ数、CFG、シード、サイズなどの主な項目。値の文字は選択してコピーできます。
- **その他のパラメーター** — 上に入らなかった項目(折りたたみ)
- **撮影情報(Exif)** — カメラやスマホで撮った写真(JPEG / WebP / HEIC)に記録された、カメラ、レンズ、撮影日時、絞り、シャッター速度、ISO 感度、焦点距離、露出補正などです(該当する画像のみ表示)。
- **生のメタデータ** — 画像に入っていた元の文字列(折りたたみ)。うまく読めない画像を調べるときに使います。
**カードの最小化。** プロンプト、ネガティブプロンプト、キャラクター別プロンプト、パラメーター、撮影情報の各カードは、見出し(▾ の付いた行)をクリックすると、最小化できます(▸ になります)。もう一度クリックすると、元に戻ります。最小化の状態は保存され、次回起動時や、別の画像に切り替えたあとも保たれます。
**位置情報(GPS)。** 写真に撮影場所の緯度・経度が記録されていても、初期設定では表示せず、「記録あり」とだけ出します(画面を人に見せるときに、場所が分からないように)。メニュー「設定 → 撮影情報の位置情報(GPS)を表示する」をオンにすると、緯度・経度と標高を表示します。
キャラクターの見出しの `[C3 (x=0.5, y=0.5)]` は、そのキャラクターの配置の指定です。画像を 5×5 のマス目に分けたときの位置(列は左から A〜E、行は上から 1〜5)と、横・縦の位置の割合(0〜1)を示します。NovelAI で位置を指定していなくても、中央(C3)が入ることがあります。
読み取れるのは、Stable Diffusion WebUI(A1111 / Forge)、ComfyUI、NovelAI、InvokeAI で生成した、PNG / JPEG / WebP の画像です。これ以外のツールでも、プロンプトなどが一般的な名前の項目(prompt、negative_prompt、seed、steps など)で JSON として入っていれば、「不明なツール(JSON: …)」として読めることがあります。
! SNS やチャットアプリを経由した画像、画像編集ソフトで保存し直した画像では、メタデータが消えていることがあります。その場合は「AI生成メタデータは見つかりません」と表示されます。PixAI など、サイトからダウンロードした画像も、プロンプトが画像の中に入っていないことがあります。

## 6. サムネイル
左側の一覧に、小さなサムネイルを表示します。メニュー「設定 → サムネイルを表示」で、表示するかどうかを切り替えます。メニュー「設定 → サムネイルの大きさ」で、小・中・大を選べます。サムネイルは、画面に見えている分だけを作り、メモリの上にだけ置きます(最大600枚まで。ディスクには保存しません)。そのため、アプリを再起動すると、作り直しになります。

## 7. ファイル操作
左側の一覧で、画像ファイルを操作できます。一覧の項目を右クリックするか、キーで操作します。Ctrl や Shift を押しながらクリックすると、複数のファイルをまとめて選べます(右パネルと中央に表示するのは、その中の1枚です)。
- **コピー / 切り取り / 貼り付け** — OS のクリップボードを使うので、ファイルマネージャー(Windows はエクスプローラー、Mac は Finder)に貼り付けたり、ファイルマネージャーでコピーした画像を、いま開いているフォルダに貼り付けたりできます。貼り付けできるのは画像ファイルだけで、同じ名前があるときは「名前 (2)」のように別の名前になります。
  切り取りを貼り付けると移動になります。Linux では、GNOME(Files / Nautilus など)と KDE(Dolphin)の決まりで切り取りを伝えます。**Mac の Finder は、切り取りを受け取れないので、Finder に貼り付けるとコピーになります**(PromptLoupe の中で貼り付けたときは移動します)。
- **名前の変更** — 拡張子はそのままで、名前の部分だけを変えます。1枚だけ選んでいるときに使えます。
- **削除** — ごみ箱に移します。誤って消さないよう、初期設定では**使えません**。メニュー「設定 → ファイル操作 → 削除を許可する」をオンにしたときだけ使えます。「削除の前に確認する」(初期設定はオン)をオフにすると、確認なしで削除します。
- **ファイルマネージャーで表示** — 選んだ画像を選択した状態で、ファイルマネージャー(Windows はエクスプローラー、Mac は Finder)を開きます。Linux では、ファイルマネージャーによってはフォルダだけを開きます。
- **そのほか** — 既定のアプリで開く、ファイルのパスをコピー、画像をコピー(他のアプリに貼り付け用)、プロンプトをコピー、プロパティ(Windows のみ)。
**ドラッグ&ドロップで持ち出す。** 一覧の画像をドラッグして、エクスプローラーのフォルダや、他のアプリ(チャットや画像編集ソフトなど)にドロップできます。ふつうはコピーです。**Shift を押しながらドラッグを始める**と、移動もできます(移動したファイルは、一覧から消えます)。
! **Linux では、一覧からのドラッグでの持ち出しは使えません**(使っている部品 Avalonia 11.3 が、Linux でほかのアプリへのドラッグに対応していないため)。代わりに、コピー(Ctrl+C)してファイルマネージャーに貼り付けてください。
! 外から PromptLoupe にファイルやフォルダをドロップしたときは、「1. 画像を開く」のとおり、それを開きます(コピーはしません)。
! 開いているフォルダの画像が、ほかのアプリで移動・削除・名前変更されたときは、一覧にも反映します(切り取ってファイルマネージャーに貼り付けたときなど)。新しく増えた画像は、フォルダを開き直すと一覧に出ます。

## 8. 全画面表示
**F11** キー、メニュー「表示 → 全画面表示」、または画像の右下の「全画面」ボタンで、全画面表示になります。メニュー、左右のパネル、ステータスバーを隠して、画像だけを画面いっぱいに出します。全画面のままでも、←→ などで画像を切り替えたり、ホイールでズームしたりできます。**Esc** または F11 で、元の表示に戻ります。

## 9. タグの色分け
プロンプトのタグ(チップ)を、種類ごとに色分けして表示します。色はダーク/ライトのテーマに合わせて変わります。
- 青 — 一般(blue hair、smile など)
- 赤 — アーティスト
- 紫 — 作品名
- 緑 — キャラクター名
- 橙 — メタ(highres など)
- 青緑 — `<lora:…>` など(辞書は不要)
上の5つの分類(青・赤・紫・緑・橙)には、**Danbooru のタグ辞書**が必要です。辞書は、a1111-sd-webui-tagcomplete などで配布されている `danbooru.csv`(1行が「タグ,分類,件数,別名」の形式)を、ご自身で用意してください。アプリには同梱していません。
現時点では、次の URL の `danbooru.csv` をダウンロードして使うことをおすすめします。開いたページで、ファイルの表示欄の右上にある下向き矢印のボタン(「Download raw file」)を押すと保存できます。{br}`https://github.com/DominikDoom/a1111-sd-webui-tagcomplete/blob/main/tags/danbooru.csv`{br}同じ場所にある e621.csv や derpibooru.csv などは、分類の番号の意味が違うため、正しく色分けされません。
- メニュー「設定 → タグの色分け → タグ辞書(danbooru.csv)を読み込む」で、ファイルを選びます。
- 読み込んだ辞書は、設定の保存先(「11. 設定の保存」を参照)に `danbooru.csv` としてコピーされ、次回からは自動で使われます。
- 辞書にないタグは、色が付きません。「色分けする」のチェックで、色分けそのもののオン/オフを切り替えられます。「タグ辞書を外す」で、辞書を使わない状態に戻せます。
- スペースと `_` は同じ扱いで、`artist:名前` のように書かれたタグはアーティストとして扱います。

## 10. タグの集計
メニュー「表示 → タグの集計」または **Ctrl+T** で、集計のウィンドウを開きます。画像のプロンプトに使われているタグを、**そのタグを使っている画像の枚数**の多い順に並べます。1枚の中で同じタグが何度出てきても、1枚と数えます。割合は、メタデータのある画像の枚数に対する割合です。
- **集計するプロンプト** — プロンプト / ネガティブプロンプト / キャラクター別プロンプト から選びます。
- **範囲** — 「一覧に表示中の画像」(絞り込みの結果)か、「フォルダのすべての画像」を選びます。
- **並び替え** — 列の見出し(✓ / タグ / 分類 / 枚数 / 割合)をクリックすると、その列で並び替えます。もう一度クリックすると逆順になります。見出しの ▲ は昇順、▼ は降順です。
- **タグを検索** — 一覧の中からタグを探します(スペースと _ は同じ扱い)。
行を**ダブルクリック**するか、選んで **Enter** を押すと、そのタグが絞り込み欄に入ります(もう一度で外れます)。絞り込み欄に入っているタグには `✓` が付きます。範囲が「一覧に表示中の画像」のときは、絞り込むと集計も自動で変わるので、たとえばキャラクター名で絞り込むと、そのキャラクターと一緒によく使っているタグが分かります。
右クリックで、選んだタグをカンマ区切りでコピー(Ctrl+C。プロンプトに貼り付けられます)、または一覧をタグ・分類・枚数・割合のタブ区切りでコピー(表計算ソフトに貼り付けられます)できます。タグ辞書を読み込んでいれば、タグは色分けされ、「分類」の欄に種類が出ます。
! タグは、重みやかっこを外し、小文字にして、`_` をスペースにした形で数えます(`(blue_hair:1.2)` と `blue hair` は同じタグ)。メタデータの読み込み中は、読み込みが進むにつれて数が増えていきます。

## 11. 設定の保存
テーマ(OS の設定に合わせる / ダーク / ライト。メニュー「設定 → テーマ」)、サブフォルダの深さ、フォルダのパスの表示、フォルダツリーの最小化と高さ、サムネイルの表示と大きさ、絞り込みの検索対象、フィット/100%の選択、削除に関する設定、タグの色分け、タグの集計の条件は、次回起動時も保持されます。保存先は {settings} です。このファイルを削除すると、すべて初期設定に戻ります。
! Windows では、1.x(WPF 版)と同じ設定のファイルを使うので、1.x の設定がそのまま引き継がれます。

## 12. 困ったとき
- **HEIC が表示されない** — HEIC は OS の機能で読むので、上の「表示できる画像形式」にある拡張機能・プラグインを入れてください(入っていないときは、画像の欄に入れ方が出ます)。Linux では、libheif の版によって、特殊な作りの HEIC を読めないことがあります。HEIC のメタデータは、拡張機能がなくても読めます。
- **HEIC のプロンプトが出ない** — HEIC からは、EXIF に入っている情報(撮影情報など)だけを読みます。プロンプトをよく読めるのは PNG / JPEG / WebP です。
- **GIF が動かない** — アニメーションは先頭のフレームだけ表示します。
- **絞り込んでも何も出ない** — 「検索対象」のチェックと、カンマ区切りになっているかを確認してください。メタデータの読み込み中のこともあります。
- **削除できない** — 初期設定では削除が無効です。メニュー「設定 → ファイル操作 → 削除を許可する」をオンにしてください。
- **タグに色が付かない** — 「設定 → タグの色分け」で「色分けする」がオンか、辞書を読み込んでいるかを確認してください(`<lora:…>` だけは辞書なしで色が付きます)。
- **メタデータが一部しか出ない** — 「生のメタデータ」を開いて、元の文字列に情報が入っているかを確認してください。
- **一覧からドラッグできない(Linux)** — Linux では、ドラッグでの持ち出しに対応していません。コピー(Ctrl+C)して、ファイルマネージャーに貼り付けてください。
